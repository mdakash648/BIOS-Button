# ⚡ এক ক্লিকে BIOS/UEFI-তে রিস্টার্ট শর্টকাট

একটা ডেস্কটপ শর্টকাট তৈরি করুন, যেটায় ডাবল ক্লিক করলেই PC সরাসরি BIOS/UEFI Firmware Settings-এ রিস্টার্ট হয়ে যাবে — বারবার কীবোর্ড কী (DEL, F2, F12 ইত্যাদি) চাপার ঝামেলা ছাড়াই।

## শর্টকাট তৈরির ধাপ

1. **নতুন শর্টকাট তৈরি করুন**
   ডেস্কটপে (বা যেকোনো ফোল্ডারে) মাউসের **Right Click** করুন → `New` → `Shortcut`

2. **কমান্ড পেস্ট করুন**
   "Type the location of the item" বক্সে নিচের কমান্ডটা কপি-পেস্ট করুন:
   ```cmd
   C:\Windows\System32\shutdown.exe /r /t 0 /fw
   ```

3. **নাম দিন**
   `Next` ক্লিক করার পর শর্টকাটের একটা নাম দিন, যেমন:
   ```
   Bios
   ```

4. **তৈরি সম্পন্ন করুন**
   `Finish` ক্লিক করুন — শর্টকাটটা এখন ডেস্কটপে তৈরি হয়ে যাবে।

5. **Administrator পারমিশন সেট করুন**
   তৈরি করা শর্টকাটে **Right Click** করে `Properties` এ যান।

6. **Advanced সেটিংস চালু করুন**
   `Advanced...` বাটনে ক্লিক করে `Run as administrator` অপশনে টিক দিন।

7. **সেভ করুন**
   `OK` → `OK` → `OK` চাপুন সব উইন্ডো বন্ধ করার জন্য।

---

## ব্যবহারবিধি

8. যখনই BIOS/UEFI-তে ঢুকতে চাইবেন, শুধু **Bios** শর্টকাটে ডাবল ক্লিক করুন।
9. একটা কনফার্মেশন উইন্ডো আসবে, সেখানে **Yes** ক্লিক করুন।
10. PC রিস্টার্ট হয়ে সরাসরি BIOS/UEFI Firmware Settings-এ চলে যাবে। ✅

---

## কমান্ডের ব্যাখ্যা

```cmd
shutdown.exe /r /t 0 /fw
```

| প্যারামিটার | কাজ |
|---|---|
| `/r` | PC রিস্টার্ট করবে (শাটডাউন না) |
| `/t 0` | ০ সেকেন্ড অপেক্ষা করে সাথে সাথে রিস্টার্ট শুরু হবে |
| `/fw` | পরবর্তী বুটে সরাসরি Firmware (BIOS/UEFI) সেটিংসে ঢুকবে |

## গুরুত্বপূর্ণ টিপস

- এই শর্টকাট শুধুমাত্র তখনই কাজ করবে যদি আপনার মাদারবোর্ড **UEFI মোডে** থাকে (পুরনো Legacy BIOS-এ কাজ নাও করতে পারে)।
- `Run as administrator` অপশন চালু না করলে শর্টকাট কাজ করবে না, তাই এই ধাপ স্কিপ করবেন না।
- কাজ চলাকালীন কোনো ফাইল সেভ না করা অবস্থায় শর্টকাটে ক্লিক করবেন না — এটা সাথে সাথে রিস্টার্ট করে দেয়।
